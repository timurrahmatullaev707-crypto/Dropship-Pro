Telegram Buyurtma Integratsiyasi

Sayt orqali yangi buyurtma berilganda, xaridor ma'lumotlari darhol ushbu Telegram bot va Chat ID ga yuboriladi.

@BotFather orqali yaratilgan bot tokeni
Xabar borishi kerak bo'lgan shaxsiy profilingiz yoki guruhingiz ID raqami

Botni Qanday Sozlash Kerak?

1. Bot yaratish: Telegramda @BotFather ga kiring va /newbot buyrug'ini yuboring.

2. Tokenni olish: BotFather bergan API tokenni yuqoridagi Telegram Bot Token qatoriga qo'ying.

3. Chat ID ni aniqlash: O'z profilingiz ID raqamini bilish uchun Telegramda @userinfobot ga /start bosing va chiqqan Id raqamini Chat ID qatoriga yozing.

4. Botni ishga tushirish: Yangi ochgan botingizga kiring va /start tugmasini bosing (aks holda bot sizga yozolmaydi).

So'ng "Telegramni Sinab Ko'rish" tugmasini bosing!
